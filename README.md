# ⚡ OFFLINE BRUTEFORCE LAB

### Java + Python Cybersecurity Laboratory

A lightweight, offline cybersecurity laboratory designed to demonstrate password security, authentication protection, and defensive brute-force prevention.

Built with performance and compatibility in mind, including older and lower-powered computers.

---

## 🖥️ Features

- **Java Edition** – standalone Java implementation.
- **Python Edition** – alternative implementation.
- **CSS Interface** – dark cybersecurity-themed interface.
- **Offline Operation** – no internet connection required.
- **Password Analyzer** – evaluates password complexity.
- **Brute-Force Simulation** – demonstrates attacks against a local simulated authentication system.
- **Rate-Limit Testing** – demonstrates login throttling.
- **Account Lockout Simulation** – tests defensive authentication policies.
- **Automatic Log Cleanup** – manages diagnostic files.
- **1 MB Log Limit** – keeps log storage controlled.
- **Resource Management** – configurable CPU and memory limits.
- **Multitasking** – controlled concurrent simulations.

## ⚙️ Performance

Designed with lower-powered hardware in mind.

Performance considerations:

- Configurable processing limits.
- Controlled background tasks.
- Limited log storage.
- Automatic temporary-file cleanup.
- No unnecessary network requests.
- Lightweight execution.
